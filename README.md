## Organização

Cada lista fica em uma pasta dentro de `atividades`. Na Lista 01, as respostas teóricas estão em um arquivo Markdown e cada item prático está em um arquivo JavaScript.

```text
atividades/
  lista-01/
    questoes-teoricas.md
    questao-2-a.js
    questao-2-b.js
    ...
    index.html
```

## Como executar a Lista 01

As soluções práticas usam o ambiente do navegador, com `prompt` e `alert`. Abra `atividades/lista-01/index.html` no navegador e escolha a questão.
